# Аддон «Колизей» (Minecraft Bedrock 1.26+)

Полноценный аддон для Minecraft Bedrock (Android, Windows, iOS) с системой гладиаторских боев, автоматическими волнами, экономикой сестерциев и поддержкой мультиплеера.

---

## 📦 Быстрая установка

### Для Android:
1. Скопируйте файл **`Colosseum.mcaddon`** на ваш Android-смартфон или планшет.
2. Откройте файл через любой файловый менеджер (например, CX Проводник, Total Commander, ZArchiver или стандартный проводник).
3. Выберите **«Открыть с помощью Minecraft»**.
4. Игра автоматически запустится и последовательно импортирует **Colosseum_BP** и **Colosseum_RP**.
5. При создании или редактировании мира:
   - В разделе **«Наборы ресурсов»** активируйте **«Колизей RP»**.
   - В разделе **«Наборы параметров»** активируйте **«Колизей BP»**.
   - В разделе **«Эксперименты» (Experiments)** обязательно включите пункт:
     - **Бета-версии API (Beta APIs)** — требуется для работы скриптовой логики волн (`@minecraft/server`).

## ⚔ Игровой процесс и возможности

### 1. Предметы
- **Боевой рог Колизея (`colosseum:start_fight`)**: Запускает сражение на арене. При повторном нажатии во время боя сообщает текущий статус.
- **Сестерций арены (`colosseum:coin`)**: Основная валюта арены, стакается до 64 шт. Выпадает с гладиаторов и начисляется за победу в волнах.
- **Гладиус арены (`colosseum:gladius`)**: Римский меч с уроном 8 и прочностью 1561.
- **Щит гладиатора (`colosseum:shield`)**: Скутум для экипировки во вторую руку.
- **Кубок Триумфатора (`colosseum:trophy`)**: Редкая награда за победу над финальным боссом.

### 2. Волны гладиаторов
1. **Волна 1**: 6 обычных гладиаторов (Награда: 15 монет каждому участнику)
2. **Волна 2**: 4 обычных + 3 тяжёлых танка (Награда: 30 монет каждому)
3. **Волна 3**: 4 быстрых + 3 обычных + 2 лучника (Награда: 50 монет каждому)
4. **Волна 4**: 2 чемпиона + 4 лучника + 3 тяжёлых (Награда: 80 монет каждому)
5. **Волна 5**: 1 Император Арены (Босс) + 2 чемпиона + 4 быстрых (Награда: 150 монет каждому + Кубок Триумфатора)
- **Бесконечный режим**: После 5-й волны игра может продолжаться с нарастающей сложностью и увеличивающимися наградами.

### 3. Мультиплеер (Multiplayer-Friendly)
- Все игроки, находящиеся в радиусе арены во время боя, получают синхронный **Actionbar HUD**:
  `⚔ Волна: 1/5 | Врагов: 6 | Бойцов: 2`
- Экранные титры и звуковые сигналы рога слышны всем участникам.
- Монеты за завершение волны начисляются **каждому живому игроку** на арене.
- Если один игрок погиб, бой не прекращается; поражение наступает только если пали **все** бойцы на арене.

## ⚙ Настройка координат арены

Все настройки находятся в файле `Colosseum_BP/scripts/config.js`:

```javascript
export const ARENA_CONFIG = {
  // true = центр арены будет там, где игрок дунул в рог
  // false = бой всегда происходит по фиксированным координатам fixedCenter
  useDynamicCenter: false,

  fixedCenter: {
    x: 0,
    y: 65,
    z: 0
  },

  arenaRadius: 28, // Радиус арены в блоках
  teleportPlayersOnStart: false // Телепортировать игроков в центр при старте
};
```

Если у вас уже построена своя арена в мире, просто укажите координаты её центра в `fixedCenter: { x, y, z }`!
