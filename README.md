# Аддон «Колизей» v1.5.0 (Minecraft Bedrock 1.26+)

Полноценный аддон для Minecraft Bedrock (Android, Windows, iOS) с системой гладиаторских боев, тактическим ИИ, командными синергиями, автоматическими волнами, экономикой сестерциев и поддержкой мультиплеера.

---

## ⚔ Классы Гладиаторов и Тактический ИИ (v1.5.0)

1. **Гладиатор-Медик (`colosseum:gladiator_medic`)**:
   - Дистанционный бросок взрывных зелий исцеления (Splash Potion) раненым союзникам (до 15 блоков) с AoE лечением по площади (Мгновенное лечение + Регенерация + Стойкость).
   - Самолечение при получении урона (HP < 60%).
   - Защитное зелье замедления и слабости под ноги нападающего игрока.
   - Боевой клич поддержки боевым рогом раз в 25 сек (бафф скорости и стойкости отряду).
2. **Гладиатор-Берсерк (`colosseum:gladiator_berserk`)**:
   - Яростный боец с двумя топорами без щита.
   - Механика неистовой ярости (ENRAGED) при HP < 45%: боевой рык, бафф Силы и Скорости II, игнорирование отхода к медику.
   - Вдохновляет ближайших быстрых гладиаторов скоростью (заражение яростью).
3. **Гладиатор-Ретиарий (`colosseum:gladiator_retiarius`)**:
   - Воин с трезубцем и сетью.
   - Бросает ловчую сеть (кулдаун 11 сек): накладывает Замедление IV на 4 сек и Слабость.
   - Командное целеуказание: лучники и танки мгновенно фокусируют атаку на опутаной цели.
4. **Быстрый Гладиатор (Акробат)**: Акробатический прыжок (Leap) на цель и отскок назад (Hit & Run).
5. **Щитоносцы и Танки**: Тактический рывок со щитом (Shield Dash), перехват ударов от медика и пассивная аура стойкости рядом с Медиком.
6. **Лучники**: Умный кайтинг к танкам и щитоносцам при сближении игрока.

## 📦 Волны гладиаторов
1. **Волна 1**: 6 обычных новобранцев (Награда: 15 монет каждому)
2. **Волна 2**: 4 обычных + 3 тяжёлых танка (Награда: 30 монет каждому)
3. **Волна 3**: 3 быстрых + 2 обычных + 2 лучника + 1 Ретиарий + 1 Медик (Награда: 60 монет)
4. **Волна 4**: 2 чемпиона + 2 тяжёлых + 2 Берсерка + 1 Ретиарий + 2 лучника + 1 Медик (Награда: 95 монет)
5. **Волна 5**: 1 Император Арены (Босс) + 2 чемпиона + 2 Берсерка + 1 Ретиарий + 2 быстрых + 1 Медик (Награда: 175 монет + Кубок Триумфатора)
- **Бесконечный режим**: Динамическое нарастание сложности с участием всех классов гладиаторов.

### 3. Мультиплеер (Multiplayer-Friendly)
- Все игроки, находящиеся в радиусе арены во время боя, получают синхронный **Actionbar HUD**:
  `⚔ Волна: 1/5 | Врагов: 6 | Бойцов: 2`
- Экранные титры и звуковые сигналы рога слышны всем участникам.
- Монеты за завершение волны начисляются **каждому живому игроку** на арене.
- Если один игрок погиб, бой не прекращается; поражение наступает только если пали **все** бойцы на арене.

## ⚙ Настройка координат арены

Все настройки находятся в файле `Colosseum_BP/scripts/config.js`:

```javascript
export const ARENA_CONFIG = {
  // true = центр арены будет там, где игрок дунул в рог
  // false = бой всегда происходит по фиксированным координатам fixedCenter
  useDynamicCenter: false,

  fixedCenter: {
    x: 0,
    y: 65,
    z: 0
  },

  arenaRadius: 28, // Радиус арены в блоках
  teleportPlayersOnStart: false // Телепортировать игроков в центр при старте
};
```

Если у вас уже построена своя арена в мире, просто укажите координаты её центра в `fixedCenter: { x, y, z }`!
